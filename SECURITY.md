# Sécurité / Security

*[English below](#english)*

## Signaler une faille

Ne publiez jamais une faille dans une *issue*. Deux canaux privés :

- le **signalement privé de GitHub** de ce dépôt : onglet *Security and quality*, puis
  *Report a vulnerability* ;
- l'e-mail **contact@zipero.fr**.

Indiquez si possible le fichier ou la fonction concernés, les étapes pour reproduire le problème
(un fichier d'entrée qui le déclenche) et ce qu'un attaquant pourrait en faire.

Nos engagements : accuser réception, vous dire si nous confirmons le problème, corriger une faille
confirmée de gravité haute ou critique sous 48 heures après sa confirmation, vous prévenir quand
la correction est publiée et vous citer si vous le souhaitez. Pas de récompense financière. Si
vous signalez en privé et de bonne foi, nous n'engagerons aucune poursuite contre vous pour cette
recherche.

La politique complète, qui couvre aussi le site zipero.fr, est en ligne :
[zipero.fr/securite](https://zipero.fr/securite).

## Versions suivies

Seule la dernière version de la branche `main` reçoit des correctifs.

## English

Never disclose a vulnerability in an issue. Two private channels:

- this repository's **GitHub private vulnerability reporting**: *Security and quality* tab, then
  *Report a vulnerability*;
- email **contact@zipero.fr**.

If possible, include the affected file or function, steps to reproduce (an input file that
triggers the problem) and what an attacker could do with it.

We commit to: acknowledging your report, telling you whether we confirm the problem, fixing a
confirmed high or critical vulnerability within 48 hours of confirming it, letting you know when
the fix is published and crediting you if you wish. No financial rewards. If you report privately
and in good faith, we will not take legal action against you for this research.

The full policy, which also covers the zipero.fr website:
[zipero.fr/en/security](https://zipero.fr/en/security). Only the latest version of the `main`
branch receives fixes.
